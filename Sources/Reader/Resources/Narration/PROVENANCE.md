# Reader local narration

Reader's narration adapter reuses Pat Carroll's R2M backend copied on 16 November 2026 from `/Users/pc/Dropbox/Software/Programs/R2M/Backend`, with that checkout left unchanged. The source checkout HEAD was `ab2bc9bc3ddd88f49a519370828637f1ad64deaf`; this is a snapshot of the actual local files, including any local fixes, rather than a claim those files match that commit.

`R2MBackend/paper.py`, `model_paths.py`, and `loudness.py` are preserved copies. Reader's copy of `reader.py` additionally normalizes intrinsic PDF page rotation only in its unsaved parsing document, checks layout output against every native text span, and falls back to native page text if the layout engine omits content. This fixes a confirmed PyMuPDF 2.0 case where a selectable page with `/Rotate 90` produced empty layout text. Source PDF bytes and the original R2M project remain unchanged. `models.json` pins exact local Kokoro speech and DeBERTa cleanup model inputs. The adapter overrides the model root and FFmpeg path in its own worker process. No account, API key or hosted inference is used. The Python worker runs with Hugging Face/Transformers offline flags and uses local model paths.

Setup makes independent APFS file clones, or ordinary copies, of the prepared R2M runtime, FFmpeg, and already installed speech and cleanup model files into `ReaderRuntime`. Setup verifies model SHA256 hashes. It never modifies R2M, and the resulting app/ReaderRuntime model folder do not depend on R2M remaining installed. Runtime and model files are regenerable dependencies; irreplaceable reading text, generated listening scripts, plans, MP3 audio and job metadata belong to the configured Reader library.

Cleanup is a reversible derivative. DeBERTa scores candidate publisher notices; it does not rewrite the author's prose. R2M's conservative rules identify citations, reference entries and repeated page furniture. The original document is retained. Each job saves extracted text, the reversible plan, the spoken script, settings and model revisions so the result can be inspected outside Reader. Uncertain author text is preserved. Layout extraction can still struggle with unusual multi-column PDFs, and all automated cleanup should be reviewed before relying on an audio rendition of technical material.

Retain `R2MBackend/THIRD_PARTY_NOTICES.md`, its `Licenses` folder and the runtime package metadata when distributing this app. The runtime includes GPLv3 FFmpeg/eSpeak NG and AGPLv3 PyMuPDF/MuPDF, with their original notices and upstream source references. The copied runtime has not been re-licensed by this adapter. Kokoro weights use Apache 2.0 and the cleanup classifier uses MIT. Reader does not include or use R2M's optional chat model.
