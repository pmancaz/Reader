No overall application licence has been selected for Reader. Publishing this source does not itself add an open-source licence grant to Pat Carroll's original Reader code. That decision remains open.

The retained third-party files keep their own notices and licence terms. This note does not replace or relax those terms.

See the [runtime notices](../Sources/Reader/Resources/Narration/R2MBackend/THIRD_PARTY_NOTICES.md) and the package metadata generated by runtime setup.

This publication contains source and small demonstration assets, not runtime binaries, model weights or an app installer. Any later binary distribution needs to retain the applicable notices and address the corresponding-source requirements for the actual dependencies supplied.
